# GamePulse Analytics

## Overview

GamePulse Analytics is a cloud-based analytics platform designed around the business needs of Overtime Gaming.

The platform aggregates public gaming data from YouTube and Twitch to identify high-growth games, creators, and content opportunities.

## Tech Stack

- Python
- YouTube Data API
- Twitch API
- AWS S3 (planned)
- PostgreSQL (planned)
- Power BI (planned)
